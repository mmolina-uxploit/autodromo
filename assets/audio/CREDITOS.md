# Créditos de sonido

Todas las grabaciones son de dominio público (CC0): se pueden usar, modificar y publicar sin pagar ni atribuir. Igual las nombramos.

Los archivos de esta carpeta se generan con `tools/audio/preparar_sonidos.py` a partir de las grabaciones originales; no se editan a mano.
